What changed in v2

Three themed sections replace the flat dashboard. The page is about patterns now, not counts.

Areav1v2
Page nameMetrics→ Overview (chosen; alt: Trends, Rhythm)
StructureFlat stats + charts→ Cycle / Symptoms / Mood themes
Fourth metricDays logged→ Cycle variation + 6-cycle length trend
Today cardOne phase focus→ Phase tip + personal pattern
Pattern cardsText + percentage→ Mini charts + sample size + try-this
Entry pointCalendar→ Calendar only
On “days logged”: the number still appears as a sample-size caption (“68 tracked days”) where it qualifies a chart, but it no longer takes a metric tile. The fourth tile is cycle variation, backed by a six-cycle length chart — a real trend.
On “themes”: I read this as grouping the page by cycle theme — Cycle, Symptoms, Mood — rather than one flat grid. If you meant a different grouping, say so and I’ll re-cut it.
Early state: thin data shows honest dashes and “keep logging” prompts. The phase tips stay browsable from day one.
What stayed: the 60-day mood trend, symptom phase split and phase tips are unchanged in substance; they are just re-homed and re-framed.

Decisions from this round

The approved direction, kept here for the implementation.

1

Which tab name? Overview chosen

Overview won: it covers the current cycle status and the longer trends. Trends was the runner-up; Rhythm remains the warmer alternative.

2

6-cycle length chart Included

It replaces the days-logged tile with a real trend and makes cycle regularity visible at a glance. The data is already in periodStarts.

3

Personal pattern row in Today Included

It connects today’s guidance to the user’s own log (“headaches tend to show up now”), and falls back to “usually show up in…” when today’s phase does not match.

4

Data-derived pattern cards Included

Use the existing symptomPatterns, moodPhases and periodStarts. Hide a card when its sample is too small; always show the denominator.
